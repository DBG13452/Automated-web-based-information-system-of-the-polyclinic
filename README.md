# Clinic Information System

Учебный веб-проект по теме: автоматизированная информационная система поликлиники.

## Стек

- Frontend: React + Vite
- Backend: FastAPI
- Database: PostgreSQL
- ORM: SQLAlchemy

## Структура

```text
frontend/  # клиентское приложение
backend/   # серверное приложение
docs/      # проектная документация
```

## Текущий этап

Инициализирован каркас проекта. Следующим этапом будет настройка backend-конфигурации, подключения к БД и схемы данных MVP.
