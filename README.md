# Clinic Information System

Учебный веб-проект по теме: автоматизированная информационная система поликлиники.

## Стек

- Frontend: React + Vite
- Backend: FastAPI
- Database: PostgreSQL
- ORM: SQLAlchemy

## Структура

```text
frontend/  # клиентское приложение
backend/   # серверное приложение
```
