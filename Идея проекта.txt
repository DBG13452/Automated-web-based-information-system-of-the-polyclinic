Тема: Автоматизированная информационная веб-система поликлиники для учета пациентов, записи на прием, 
ведения назначений и контроля лечения

Суть проекта - разработать программу для поликлиники, которая позволяет автоматизировать основные процессы работы поликлиники
А именно: 
- хранить данные о пациентах
- хранить данные о персонале и специализациях врачей
- организовывать запись пациентов на прием
- фиксировать результаты приема
- назначать медикаменты и процедуры
- отслеживать выполнение процедур
- учитывать больничные листы

Цель проекта: Разработать автоматизированную информационную систему поликлиники, обеспечивающую учет пациентов, организацию записи на прием, 
ведение врачебных заключений, назначение лечения и контроль выполнения процедур

Модули проекта:
1. Модуль работы с пациентами
Будет позволять: добавлять нового пациента, редактировать данные пациента, удалять пациента, искать их по ФИО, телефону, полису или СНИЛС, а также просматривать карточку пациента

2. Модуль работы с персоналом
Будет позволять: Просматривать список сотрудников, видеть должность и специализацию, фильтровать врачей по специальности и использовать врача при создании талона

3. Модуль расписания и записи на прием
Будет позволять: Создавать талоны, просматривать свободные и занятые талоны, записывать пациента на выбранный талон, отменять записи и находить расписание конкретного врача

4. Модуль приема пациента
Будет позволять: Открыть прием по талону, внести осмотр и рекомендации, зафиксировать диагноз, оформить больничный лист если это будет нужно

5. Модуль назначения лечения
Будет позволять: Назначать медикаменты, указать способ применения, указывать период приема, назначать процедуры, указывать количество посещений 

6. Модуль контроля лечения 
Будет позволять: Видеть какие процедуры назначены пациент, видеть сколько процедур уже пройдено, выявлять пациентов которые не завершили курс процедур, выявлять пациентов которые вообще не посетили назначенные процедуры 

7. Модуль отчетов ???????
Будет позволять: список пациентов которые не завершили лечение, которые не посетили процедуры, врачи с большой нагрузкой, пациенты с длительным лечением, статистика по диагнозам и назначениям


Сценарии работы системы:

Сценарий 1. Запись пациента на прием
Регистратор открывает список пациентов.
Находит нужного пациента или создает нового.
Открывает список доступных талонов.
Выбирает врача, дату и время.
Создает запись пациента на прием.

Сценарий 2. Проведение приема врачом
Врач открывает список записанных пациентов.
Выбирает нужный талон.
Вносит данные осмотра и рекомендации.
Указывает поставленный диагноз.
При необходимости оформляет больничный лист.

Сценарий 3. Назначение лечения
После постановки диагноза врач выбирает медикаменты.
Указывает способ и период применения.
При необходимости назначает процедуры.
Указывает количество посещений процедур.

Сценарий 4. Контроль прохождения процедур
Медицинский работник или администратор открывает список назначенных процедур.
Видит график процедур пациента.
Отмечает посещения.
Система определяет:
завершен курс или нет
были ли пропущены процедуры

Сценарий 5. Получение отчетов
Пользователь открывает раздел отчетов.
Выбирает нужный отчет.
Получает итоговую таблицу по данным БД.

Пример взаимодействия:
Например, регистратор хочет записать пациента:

React открывает страницу записи.
Отправляет запрос на backend.
Backend получает из PostgreSQL свободные талоны.
React показывает их в таблице.
Пользователь выбирает талон.
Backend создает запись в таблице Запись.

Или врач завершает прием:

Открывает запись пациента.
Вводит осмотр и рекомендации.
Выбирает диагноз.
Назначает лекарства и процедуры.
Backend сохраняет это в таблицы
